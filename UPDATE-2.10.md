# Recall v2.10 — retrieval accuracy and unified evidence

Transcript and locally recognized audio vectors now describe the passage itself. Titles/channels provide separate modest context, helping prevent a catchy title from pulling every moment toward the same query. Ranking adds token-boundary, accent-aware and exact-phrase evidence without letting a weak keyword match dominate a strong paraphrase. Imported titles remain eligible alongside transcripts. Arrow navigation and independent searches remain the defaults.

One ordinary search includes **Transcript**, **Audio**, **Scene** and **Title** indicators. Audio means AI transcription of player audio; Scene means a saved video image. Nearby evidence can appear together and scenes retain image previews/timestamp links. Ranking values are not calibrated confidence percentages, so the popup now shows evidence labels instead.

The first use after upgrading improves existing text vectors automatically in batches of 16, with popup progress. Search stays available during this work. Updates change vectors only after checking the saved chunk still exists and matches; deletion, replacement captions, watch dates, audio ranges and scene images are preserved. No re-import is needed. If the browser closes, remaining old chunks can resume on a later search/warmup. Errors are displayed and retried on a later index build. Existing and improved vectors can temporarily coexist during migration.

This adapts useful ideas from ma-copy without replacing current features or editing the teammate branch. See MA-COPY-REVIEW.md for the ranked findings and model comparison. On 31 controlled synthetic queries, correct first moments improved from 29/31 to 31/31; this is not a general accuracy guarantee. Bigger BGE-small and Whisper base models tied the existing models on the narrow fixtures, so the shipped models remain MiniLM, Whisper tiny.en and CLIP. No new dependency or browser permission is added; inference and saved data remain on this device.

Reload Recall in edge://extensions or chrome://extensions, refresh YouTube tabs, then reopen the popup. Version should read 2.10.0. Updating from v2.9 needs no vendor rebuild; a new source checkout must still build vendor/ as described in INSTALL.md. The ready-to-load ZIP includes the runtime.

Validation: 113 Node tests; a deliberately disabled phrase matcher failed its regression and was restored. Real-model browser checks cover safe legacy-vector upgrade and write races, Audio rendering, scene search/storage/restore, speech capture, both 53-video imports, arrow navigation and refinement. The background-window test timed out once waiting for the manual-close pause UI, then passed alone with diagnostics enabled; the original timing cause is unconfirmed. The extracted v2.10 package also passed the legacy-upgrade and background-window regressions; the manual-close path completed on that packaged run. A live isolated public YouTube check saved both a scene and speech, and returned a Scene match around 0:11.6. See TEST-REPORT.md for limits and the existing native dependency audit findings.
