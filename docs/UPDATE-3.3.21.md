# WebLapse v3.3.21

The extension is now **WebLapse**. The extension manager, toolbar, popup, settings, accessibility labels, capture window, demo player, errors and current setup documentation use the new name. ZIP downloads are named `weblapse-v3.3.21.zip`; new backup downloads use `weblapse-index-YYYY-MM-DD.json`.

The installed folder, browser identity, original `recall` IndexedDB database, settings, internal protocols, `rc` address-bar shortcut and `recall-export` backup format stay compatible. Existing history titles are preserved. Old backups remain importable. Historical release notes retain their original names.

All 290 unit tests pass. Isolated Chromium validation checks visible branding, the original database, saved titles and settings, backup export/restore, download names, popup search and keyboard access. This rename adds no permissions, models or background processing.
