# Recall v2.12 — import safety, speech guards and title notices

All four supplied findings matched active code paths and have focused regressions.

- **Imported captions stay protected.** Background transcript capture now preserves the current import flag inside the database write transaction. Retention exempts imported entries regardless of transcript method, so fetching captions no longer makes an imported video expire sooner than leaving its title alone. A normal live watch, scene capture or player-audio transcription clears that exemption and follows watched-video retention. Concurrent watch dates/flags win over older background capture data.
- **Repair existing missing flags.** Re-importing the original Takeout JSON can restore a missing flag when the original watch date exactly matches the saved record. It leaves transcript text/vectors intact. Explicit flags and newer watch dates are not overwritten. Already deleted records need the source file or a backup; missing provenance is not guessed automatically.
- **Restore retries temporary scene contention.** A scene-busy preflight rejection retries the same item four times, after 0.5, 1, 2 and 3 seconds. This happens before writes, preserving durable item progress. Stop active speech-to-text and pause caption fetching before restoring; those intentional conflicts, invalid data and transport errors are not silently retried. Sustained scene contention can still exhaust the bounded retries and shows a clear partial-progress error.
- **Automatic speech no longer guesses English from mixed subtitles.** Original audio metadata and ASR tracks take precedence. Without either, any non-English uploaded caption track marks the language undetermined and blocks the English-only automatic fallback. Missing track metadata still permits the existing fallback. The popup's **Start English transcription** action deliberately overrides language metadata; it does not make the model multilingual.
- **More Whisper noise is filtered.** Musical-note characters, BLANK_AUDIO, spaced/parenthesized/starred music tags and foreign-language tags are removed. Segments without letters and repeated standalone stock filler are dropped. Ordinary sentences and meaningful bracketed text remain. Filtering affects new speech saves and cannot eliminate every hallucination or recover correctly spoken words from noise.
- **Indexing notices show titles.** Completed, skipped and failed caption results carry the actual title when available, including failed capture messages and already-saved videos. Titles are prominent, status/reasons remain readable, and completed rows begin fading after five seconds. Repeated job updates do not reset their timers or resurrect expired rows. Overall counts stay visible, working rows remain, and reduced-motion preferences disable the opacity transition. If metadata was never available, the label is “YouTube video”; no title is invented.

No new model, dependency, permission, database schema or cloud service. Reload the existing extension and refresh YouTube tabs; version should read 2.12.0. No runtime rebuild is needed when updating from v2.9–v2.11. See [the test report](TEST-REPORT.md) for exact validation and existing audit limits.
