# Recall v2.5

Transcript fetching now defaults to six videos at once. In Library & settings → Settings → Parallel videos, choose 3, 6, 8, or 12. Twelve is the maximum supported limit; more tabs use more memory and YouTube can still throttle or block requests.

The limit applies when starting a new job. To change an existing job, pause after active videos finish, then fetch missing transcripts again. Closing settings does not stop a running job; keep the browser open.

Reload the extension after updating, then reopen settings. Existing library data is preserved.
