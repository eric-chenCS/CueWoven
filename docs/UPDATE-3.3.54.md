# CueWoven 3.3.54 beta

CueWoven now opens in the light theme by default, like most websites, even when Windows or Edge is set to dark. The light theme is applied before saved settings load, so pages no longer flash dark when they open. Dark and System are still available under Settings → Appearance, and anyone who already picked a theme keeps it. "Reset to defaults" now returns to Light.

Search, capture, models, permissions and other defaults are unchanged.

Validation: 406 unit tests and the maintained Edge browser programs pass. The preferences test now checks that a fresh install shows the light theme while the system is dark.
