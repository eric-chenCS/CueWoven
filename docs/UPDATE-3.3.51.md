# CueWoven 3.3.51 beta

Speech, visual and reranker workers now use the same local byte-loading approach as text search. One shared helper loads the packaged ONNX WebAssembly runtime once per successful worker initialization and clears its explicit configuration on success or failure. Concurrent initial model loads wait for runtime setup and retain their own results. CLIP reuses the initialized runtime across its text and image encoders. OCR uses Tesseract and is unchanged.

Twelve sequential fresh Edge profiles compared streaming and byte loading for the three additional models. All six tested speech clips retained identical transcripts and timestamps; twelve CLIP vectors and six reranker score arrays matched exactly across every run. Startup differences were small: speech 772/812 ms, CLIP text 942/994 ms, and reranker 1,169/1,149 ms. Median sampled peak private memory across the isolated browser increased about 19 MiB for speech, 87 MiB for vision with both encoders, and 53 MiB for reranking. These observations are not universal timings, extension-only RAM measurements or a fixed per-model overhead.

The helper is covered by concurrency, cleanup, retry and fetch/body failure tests. Optional real-model browser checks cover missing/corrupt runtime files and fresh-worker recovery for all three additional workers. They verify zero streaming calls, one WASM fetch per worker and cleared configuration. The maintained suite continues to cover the text path, capture, privacy boundaries, search and visual fallback. Actual audio capture/caption handoff and reranker cache/security regressions are checked separately. Existing offline text search remains equivalent over 118 queries.

Models, precision, inference batching, scoring, saved-data formats, dependencies and permissions are unchanged. This extends a precaution around V8's streaming-compilation path; it does not prove the earlier native crashes are fixed. Second-computer and longer real-user testing remain pending. Only the install ZIP is published; the store ZIP stays local.
