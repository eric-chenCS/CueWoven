# Website identity icons

These small favicon copies identify WebLapse's 31 suggested public websites. Website names and marks belong to their respective owners; inclusion does not imply endorsement. Assets were retrieved on 2026-10-18 from each domain's public favicon as served by Google's S2 favicon cache. Exceptions use official assets: TechCrunch's `https://techcrunch.com/wp-content/uploads/2015/02/cropped-cropped-favicon-gradient.png?w=32&h=32`, Stack Overflow's `https://cdn.sstatic.net/Sites/stackoverflow/Img/favicon.ico`, and Stack Exchange's `https://cdn.sstatic.net/stackexchange/img/favicon.ico`. ICO files are converted to PNG without changing the design.

They are bundled for offline display. WebLapse does not contact Google or the websites to render these icons. Custom websites continue using the browser's own favicon endpoint; unavailable images fall back to a bundled square globe. Favicons can become outdated; replace a domain's PNG when its identity changes. Existing image validation and website-permission rules are unrelated and unchanged.
