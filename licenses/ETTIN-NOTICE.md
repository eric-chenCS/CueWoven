# Ettin reranker model data

Source: https://huggingface.co/cross-encoder/ettin-reranker-32m-v1

Pinned revision: `b33e5ceb5110773ea9cf5e00c9bedc83a8c2afdd`.

The publisher identifies this model as Apache-2.0 licensed. The seven original model/tokenizer/head files are downloaded on demand and verified using `offscreen/rerank-assets.js`; they are not bundled in this source tree. The original trained weights are unchanged. CueWoven evaluates the published scoring head locally in JavaScript.

The Apache 2.0 license text is included in `ettin-LICENSE.txt`. Publisher documentation and attribution remain available at the pinned model revision above. This model is distinct from the existing MiniLM embedder.
